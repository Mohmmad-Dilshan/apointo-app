# Apointo — Complete Flutter Cross-Platform Mobile App & Platform

Apointo ("Discover. Book. Go.") is a modern service discovery, appointment booking, payments, and business management platform built with **Flutter (Dart)**.

## Project Structure
- `lib/core/`: Apointo Light Design System, AppColors, AppTypography, AppTheme, reusable widgets & sample Indian data.
- `lib/features/customer/`: Complete Customer App experience (Splash, Onboarding, Location, Auth, Home, Search, Filters, Explore, Map View, Business Profile, Service/Staff/Slot Selection, Checkout, Payments, QR Check-in, Bookings, Rewards, Reviews, Profile).
- `lib/features/provider/`: Business Owner SaaS Dashboard (Live Schedule, Calendar, Appointments, Services Catalog, Staff Management, CRM, Payouts).
- `lib/features/admin/`: Platform Admin Console (Business verification queue, GMV analytics, support desk).

## Getting Started
1. Ensure Flutter SDK 3.x is installed: `flutter doctor`
2. Install dependencies: `flutter pub get`
3. Run app on iOS/Android/Web: `flutter run`
